i使用说明

Token 怎么来

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained token，Repository access 选你的仓库，Permissions 里 Contents 设为 Read and write。Token 只保存在这台设备的浏览器里，页面不会把它发给任何第三方。

写入走什么接口

上传走 Git Data API（blob → tree → commit → ref），一次提交可带多个存档文件，不受 Contents 接口 1MB 限制；单个文件建议不超过 25MB，超限由 GitHub 拒绝。

存档安全

GitHub 免费版私有仓库不支持大文件与 Git LFS 免费额度，重要存档建议双备份；本页面是纯前端，不搭服务端，也不记录你的任何数据。

接口限流

匿名调用每小时 60 次，带 Token 每小时 5000 次。右上角实时显示剩余次数，触顶时等待整点窗口重置即可。

公共设备务必清 Token

本页部署在公开站点上，任何人都能打开，但 Token 只写进你当前浏览器的 localStorage，不会上传或内嵌在页面里。在网吧、手机借用他人设备等场景用完，请点 Token 面板里的「清除本机 Token」。

和 Game5 自动云存档的关系

Game5 里已有的 lucky-chip-sync Worker 负责游戏内自动同步（Game5Saves/{用户名}/save.json），密钥在服务端。本页是它的补充：手动查看、批量导出、跨游戏备份，以及处理 Game3、Game4 那些没有 Worker 覆盖的存档目录。两者写入同一批路径，互不冲突。

配置 GitHub Token

  1. 打开 Fine-grained tokens 创建页
  2. Repository access 选 Only select repositories，勾选你的存档仓库
  3. Permissions → Contents → Read and write
  4. 生成后粘贴到上方输入框，点「保存并验证」
只想从私有仓库导出存档时，同样需要 Token（只读权限即可）。
