使用说明

两种同步方式

本站同步（推荐）：读写全部经由 lucky-chip-sync Worker 代理，GitHub 令牌只存在 Worker 的 secret 里，页面只发送管理员密码，输一次就长期生效。浏览器直连：令牌存在你这台设备的 localStorage，不发第三方，换设备要重填一次。两种方式在右上角面板里随时切换。

为什么不能把令牌写进页面

本页是公开站点上的静态文件，令牌一旦内嵌，任何人查看源码就能拿到你仓库的写权限，包括改写和删除其他玩家的存档。所以令牌只能待在服务端 secret 或本机浏览器里，前端密码门也挡不住读源码的人。

写入走什么接口

上传走 Git Data API（blob → tree → commit → ref），一次提交可带多个存档文件，不受 Contents 接口 1MB 限制；单个文件建议不超过 25MB，超限由 GitHub 拒绝。

接口限流

匿名调用每小时 60 次，带令牌每小时 5000 次。顶部统计卡实时显示剩余次数，触顶时等待整点窗口重置即可。

公共设备用完请清除

本页在公开站点上任何人都能打开，凭据本身不内嵌在页面里：令牌只写进当前浏览器的 localStorage，管理员密码也只在提交时发一次。在网吧、借他人手机等场景用完，请点「清除本机凭据」。

和 Game5 游戏内自动同步

同一个 Worker 现在承担两件事：原有的游戏内自动同步（Game5Saves/{用户名}/save.json、Game5Accounts/…，接口与行为一字未改）和本页的管理代理（新增 /proxy 通道，只放行白名单端点、且仓库被锁死在你自己的仓库上）。
